How to use Network Explorer

Each node is a member and each line is a recorded friendship. Colours show a community assignment. Selecting a node keeps its immediate neighbourhood in view.

  1. Select a member. Click a numbered node or use Select node. Compare its connections with the different importance measures.
  2. Compare groups. Choose a community method, then toggle Reference groups. The graph stays in place so you can see membership change.
  3. Try a harder graph. Switch from strongly to weakly separated groups. Check whether the method still agrees with the known groups.

Influence replays simulated spread from chosen seeds. Link recovery hides real connections and compares methods at finding them again. Its graph shows one saved split; the scores cover twenty.

These small graphs cannot establish a universal best method. Simulated influence also does not describe observed human behaviour.
