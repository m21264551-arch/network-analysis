How to use Network Explorer

A network records things and the connections between them. In Karate Club, each numbered node is a member and each line is a recorded friendship. The other two datasets are generated graphs with known groups, so you can compare how methods behave when those groups are easier or harder to separate.

  1. Inspect a member

    Select a numbered node, or use Select node. Its details show how many neighbours it has and different measures of importance. Change Size nodes by to see how those definitions emphasise different positions.

  2. Change the groups

    Use Display groups to switch between the reference labels and a community method. Colours show membership in the selected partition. Compare the result below: modularity measures internal connection density, while NMI measures agreement with the reference groups.

  3. Make the problem harder

    Switch from Strongly separated groups to Weakly separated groups. See whether the same method still recovers the known structure. A visually neat partition does not necessarily agree with those labels.

Explore further: Influence compares simulated spread from different seed nodes. Link recovery compares methods at finding connections deliberately removed from a graph. Its scores summarise repeated splits, not predictions about new friendships.

These controls select saved experiments. Simulated influence follows a simple propagation rule; it does not establish how people actually behave.
